# Contributing Guidelines

First off, thank you for considering contributing to our simple interest calculator! We welcome contributions from everyone.

By participating in this project, you agree to abide by our [Code of Conduct](CODE_OF_CONDUCT.md).

## How to Contribute

To contribute to this project, please follow the standard "Fork-and-Pull" Git workflow:

### 1. Fork the Repository
Click the **Fork** button situated in the upper-right corner of the repository page to create a copy of the repository in your own GitHub account.

### 2. Clone the Fork
Clone the forked repository to your local machine:
```bash
git clone https://github.com/YOUR_USERNAME/simple-interest.git
cd simple-interest
```

### 3. Create a Branch
Always create a new branch for your work. Branches should be named descriptively (e.g., `feature/add-compound-interest`, `fix/typo-in-readme`).
```bash
git checkout -b your-branch-name
```

### 4. Make Changes
Make your changes to the project. Ensure your code is clean and adheres to the existing style. Write clear and informative commit messages.
```bash
git add .
git commit -m "Brief description of the changes made"
```

### 5. Push Changes to your Fork
Push the branch and your changes to your forked repository on GitHub:
```bash
git push origin your-branch-name
```

### 6. Submit a Pull Request
1. Go back to the original repository on GitHub.
2. You will see a prompt to "Compare & pull request" for your recently pushed branch. Click it.
3. Fill out the pull request template with a clear description of the problem and the solution you are providing.
4. Submit the pull request. We will review it and get back to you!

## Reporting Bugs and Requesting Features

If you don't have code to contribute but found a bug or want a new feature, please [open an issue](https://github.com/yourusername/simple-interest/issues) and describe the problem or suggestion in detail.
