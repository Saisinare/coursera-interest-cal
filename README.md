# Simple Interest Calculator

A simple bash script to calculate simple interest based on principal, annual rate of interest, and time period in years.

## Description

This repository contains a simple shell script (`simple-interest.sh`) that computes simple interest. It is designed to be a starting point for people learning how to write scripts, use Git, and contribute to open-source projects. 

### Formula

The formula for simple interest is:
`Simple Interest = (Principal * Rate * Time) / 100`

## Prerequisites

To run this script, you will need an environment that can execute bash scripts.
- Linux or macOS terminal
- Windows Subsystem for Linux (WSL) or Git Bash on Windows

## Usage

1. Clone the repository
   ```bash
   git clone https://github.com/yourusername/simple-interest.git
   cd simple-interest
   ```
2. Make the script executable
   ```bash
   chmod +x simple-interest.sh
   ```
3. Run the script and follow the prompts:
   ```bash
   ./simple-interest.sh
   ```
